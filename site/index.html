kwork-mcp: MCP-сервер для Kwork

Подключает ваш аккаунт Kwork к ИИ-агенту: Claude Code, Claude Desktop, Codex, Cursor и другим MCP-клиентам. Агент ищет проекты на бирже, читает диалоги, заказы и офферы, готовит отклики. Отправить что-то на Kwork он может, только если вы включили запись, и только после вашего подтверждения.

Что можно попросить у агента

Обычными словами, в том клиенте, где вы и так работаете.

«Найди свежие проекты про Telegram-ботов с бюджетом от 20 000 ₽ и скажи, какие мне подходят»

«Покажи диалоги с непрочитанными сообщениями и предложи ответы»

«Что с моими заказами? Где что-то ждёт моих действий?»

«Сколько у меня коннектов и какие мои отклики ещё висят?»

«Подготовь отклик на проект 3257238: 15 000 ₽, 5 дней». Агент покажет точный текст и цену и отправит только после вашего «да»

Почему агенту можно доверить аккаунт

Отклик тратит коннект, а сообщение клиент видит сразу. Поэтому сервер устроен так, чтобы агент не мог ни отправить лишнего, ни отправить дважды.

По умолчанию только чтение

Пока в конфиге стоит KWORK_ENABLE_WRITES=false, агент ничего не отправляет на Kwork.

Запись в два шага

Агент готовит точный запрос: текст, цену, получателя. На Kwork запрос уходит только после вашего подтверждения.

Без дублей

Сервер помнит каждую запись и никогда не повторяет её сам. Если связь оборвалась в момент отправки, агент сначала сверяет результат с Kwork, а новые отправки ждут.

Пароль не попадает в конфиг

Логин и пароль вводятся один раз через скрытый ввод и нигде не сохраняются. Токен лежит на вашем компьютере в файлах с правами 0600.

Только ваш аккаунт

Сервер работает с аккаунтом из KWORK_EXPECTED_USER_ID и проверяет его перед каждой записью.

Чужой текст не команда

Тексты проектов, профилей и сообщений помечаются как внешние данные, а не инструкции для агента.

Быстрый старт

Нужны macOS или Linux, Python 3.12–3.14 и uv. Windows не поддерживается.

  1. Войдите в Kwork (один раз)

    Запустите в обычном терминале:

    uvx --from kwork-mcp==1.3.0 kwork-mcp-bootstrap

    Команда скрыто спросит логин и пароль Kwork, покажет найденный аккаунт и после подтверждения сохранит токен в ~/.local/state/kwork-mcp. В конце она выведет ваш user_id, он нужен на следующем шаге.

  2. Подключите агента

    Замените 123456 на свой user_id. Для Claude Code:

    claude mcp add kwork --scope user \
  -e KWORK_EXPECTED_USER_ID=123456 \
  -e KWORK_PERSIST_TOKEN=true \
  -e KWORK_ENABLE_WRITES=false \
  -- uvx --from kwork-mcp==1.3.0 kwork-mcp
    Codex

    В ~/.codex/config.toml:

    [mcp_servers.kwork]
command = "uvx"
args = ["--from", "kwork-mcp==1.3.0", "kwork-mcp"]

[mcp_servers.kwork.env]
KWORK_EXPECTED_USER_ID = "123456"
KWORK_PERSIST_TOKEN = "true"
KWORK_ENABLE_WRITES = "false"
    Claude Desktop и Cursor

    Claude Desktop: Settings → Developer → Edit Config, файл claude_desktop_config.json. Cursor: ~/.cursor/mcp.json или .cursor/mcp.json проекта.

    {
  "mcpServers": {
    "kwork": {
      "command": "uvx",
      "args": ["--from", "kwork-mcp==1.3.0", "kwork-mcp"],
      "env": {
        "KWORK_EXPECTED_USER_ID": "123456",
        "KWORK_PERSIST_TOKEN": "true",
        "KWORK_ENABLE_WRITES": "false"
      }
    }
  }
}

    Если Claude Desktop не находит uvx, укажите полный путь из which uvx.

    Логин, пароль, токен и прокси в конфиг клиента не добавляйте: сервер с ними откажется запускаться.

  3. Проверьте

    Перезапустите клиент и попросите агента: «проверь статус аккаунта Kwork». Он покажет ваш user_id и имя.

Чтобы агент мог отправлять отклики и сообщения, замените в конфиге KWORK_ENABLE_WRITES=false на true и перезапустите клиент. Подробности, решение проблем и ручная сверка отправок описаны в README.

kwork.ru и kwork.com

По умолчанию сервер работает с kwork.ru. Для kwork.com добавьте в конфиг клиента KWORK_SITE=com. Аккаунт и токен у сайтов общие, входить заново не нужно. Биржи проектов на kwork.com нет, а диалоги, заказы и кворки работают как обычно.

Вопросы

Это официальный инструмент Kwork?

Нет. Это независимый проект с открытым кодом под лицензией MIT. Kwork его не выпускает и не поддерживает.

Может ли агент откликнуться на проект без меня?

Нет. Запись выключена по умолчанию. Когда вы её включаете, агент сначала показывает точный текст, цену и получателя, и запрос уходит на Kwork только после вашего подтверждения.

Где хранятся логин и пароль?

Нигде. Их спрашивает только kwork-mcp-bootstrap через скрытый ввод, а на диск сохраняется токен в ~/.local/state/kwork-mcp с правами 0600. Токен не шифруется, поэтому включите шифрование диска.

Какие клиенты поддерживаются?

Claude Code, Claude Desktop, Codex, Cursor и другие MCP-клиенты, которые умеют запускать локальный сервер через stdio.

Работает ли на Windows?

Нет, только macOS и Linux.

Сколько стоит?

Нисколько: kwork-mcp распространяется бесплатно под лицензией MIT.
